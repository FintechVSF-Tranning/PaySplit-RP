# PaySplit – Reports & Documents

This repository centralizes reports, analytical documents, and design resources for the **PaySplit** project. Its contents help the team align on product requirements, user-interface flows, task assignments, and database structure throughout development.

## Repository structure

- `PRD/` — Product Requirement Documents (PRDs).
  - `Product_Requirement_Document.md`: English Markdown version.
  - `Product_Requirement_Document_VI.md`: Vietnamese Markdown version.
  - `Product_Requirement_Document.pdf`: PDF version of the PRD.
- `TDD/` — Technical Design Documents (TDDs).
  - `Technical_Design_Document.md`: System architecture, bounded contexts, sequence diagrams, deployment, security, and Architecture Decision Records (ADRs).
- `docs/` — Supporting design and implementation documentation.
  - `UI_Flow.md`: user-interface flow and user-experience documentation.
  - `UI_Prompt.md`, `UI_Screen_Prompts.md`: prompts for interface design.
  - `Team_Task_Split.md`: team task allocation.
- `Database/` — Database resources.
  - `dbv1.sql`: database schema initialization script.
  - `seed_mock_data.sql`: mock data for testing.
  - `seed_mock_data.gen.py`: helper script for generating mock data.
- `design.md` — Overall project design documentation.
